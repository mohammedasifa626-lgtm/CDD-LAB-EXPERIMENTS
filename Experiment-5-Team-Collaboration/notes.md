# Experiment 5 — Team collaboration and branching strategies

Suggested feature-branch workflow:
1. Keep `main` stable.
2. Create a short-lived branch for each task.
3. Commit small, meaningful changes.
4. Push the branch and open a pull request.
5. Ask a teammate to review.
6. Run checks before merging.
7. Delete the feature branch after merging if it is no longer needed.

Example branch names: `feature/login-form`, `bugfix/input-validation`, `docs/update-setup`.
