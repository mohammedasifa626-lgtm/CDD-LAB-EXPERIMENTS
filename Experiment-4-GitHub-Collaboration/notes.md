# Experiment 4 — GitHub issues, forks, pull requests and code reviews

Use a repository you own or have permission to contribute to:
1. Create an issue describing a task or bug.
2. Fork a project if contributing to another project.
3. Clone your fork and create a feature branch.
4. Make a useful change and commit it.
5. Push the branch and open a pull request.
6. Review the diff and respond to review comments.

Example:
```bash
git switch -c docs/improve-readme
git add README.md
git commit -m "Improve README"
git push -u origin docs/improve-readme
```

Record your issue and pull request links and add your own screenshots to `screenshots/`.
