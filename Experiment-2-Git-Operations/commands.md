# Experiment 2 — Clone, push, pull, fetch and synchronization

Replace `OWNER/REPOSITORY` with a repository you own or are authorised to use.

```bash
git clone https://github.com/OWNER/REPOSITORY.git
cd REPOSITORY
git status
git remote -v
git fetch origin
git pull origin main
```

To publish your own changes:
```bash
git add .
git commit -m "Describe your change"
git push origin main
```

Record your repository URL and the results you observe. Add your own screenshots to `screenshots/`.
